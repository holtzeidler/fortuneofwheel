How to Play:

  1. Use the Admin Panel to set up your phrases
  2. Click "SPIN!" to rotate the wheel and land on a letter
  3. All instances of that letter will be revealed on the board
  4. Try to solve the phrases before all letters are revealed!
  5. Use "New Game" in Admin Panel to reset with the same phrases
